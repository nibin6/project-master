# Skill Exchange Platform

A web-based platform where users can exchange their skills with other users.

## Features

- User registration and login
- User profiles with profile pictures
- Create and list skills
- Search and discover skills
- Skill recommendations
- 1-to-1 skill exchange
- Credit-based skill exchange
- Reviews and ratings
- Session management
- Teacher and learner confirmation

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite / MySQL

## How to Run

1. Clone the repository
2. Create a virtual environment
3. Install the required packages
4. Run database migrations
5. Start the Django server

```bash
python manage.py migrate
python manage.py runserver
